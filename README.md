# TS Interop

This repository provides a tool chain to generate [Dart JS interop](https://dart.dev/interop/js-interop) bindings for JavaScript library based on Typescript declarations file (`.d.ts`)

# Packages

This repository contains a set of Dart packages. One package for the generator and one packages for each binding.

## Generator

- [ts_interop](https://github.com/blimster/ts_interop/ts_interop)

## Bindings

- [es2023](https://github.com/blimster/ts_interop/es2023)
- [webxr](https://github.com/blimster/ts_interop/webxr)
- [threejs](https://github.com/blimster/ts_interop/threejs)
